# Ayushi Singh — Portfolio

Personal portfolio of Ayushi Singh, Product Manager (lending & AI).

- **`/`**: the portfolio: about, experience, projects, case studies, skills, education and contact.
- **`/how-toorak-works`**: an interactive walkthrough of a real estate bridge loan, from a run-down rowhouse to recycled capital. A house gets rebuilt stage by stage as the loan moves from origination to exit.

## Stack

Next.js (App Router) · TypeScript · Tailwind CSS · Framer Motion · inline SVG

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Editing content

All copy lives in two files, so text can change without touching components:

- `content/portfolio.ts`: the homepage
- `content/toorak.ts`: the How Toorak Works walkthrough

Search for `TODO` to find links and assets that still need filling in.

## Notes

The house, borrower and deal figures on `/how-toorak-works` are sample values for explanation. Company totals are from public reporting, cited on the page.
